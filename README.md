### 6. Product Information & Quantities
- Live stock counts (e.g. `18 in stock`, `Only 3 Left!`, `Pre-Order Available`).
- Original slashed price vs Offer Price in Sri Lankan Rupees (Rs.).
- Pre-Order system for out-of-stock items.
- Flavor selection dropdowns/buttons.
- Quick View modal with nutrition breakdown and serving facts.

### 7. Cart, Checkout & Order Types
- **Fulfillment Types**:
  - **Self Pick Up**: Collect from Muscle Avenue Flagship Store (No. 128/A, Galle Road, Colombo 03) in ~2 hours. Free.
  - **Islandwide Delivery**: 24-48 hr courier delivery across Sri Lanka (Free on orders over Rs. 20,000).
- **Payment Methods**:
  - **Online Card Payments**: Visa, MasterCard, Amex secure form.
  - **Cash on Delivery (COD)**: Pay upon courier delivery or store pickup.
  - **Koko Pay**: 3 interest-free installments calculation.

### 8. Order Timeline & Tracking Modal
- Multi-step visual tracking progress:
  1. `Order Placed`
  2. `Payment Verified`
  3. `Order Packed`
  4. `Out for Delivery / Ready for Self Pick Up`
  5. `Delivered / Collected at Store`
- Searchable by Order ID (e.g. `MA-9841`, `MA-9842`).

### 9. Dual User Roles (Customer & Admin)
- **Customer Role**: Browse, Add to Cart, Place Orders, Place Pre-orders, View Tracking Timeline.
- **Admin Role**:
  - Admin Dashboard with sales volume, total orders, and low-stock alerts.
  - **Add New Product**: Name, Brand, Category, Price, Offer Price, Stock, Weight, Flavors, Image.
  - **Edit & Delete Products**: Live stock increment/decrement, remove items.
  - **Order Timeline Management**: Change customer order status (`Processing` -> `Packed` -> `Shipped` -> `Delivered`).

## 🚀 How to Run the Website

### Option 1: Double-click the launcher script

### Option 2: Run via Terminal
```bash
npm run dev
```
Open your browser at:
`http://localhost:3000`
